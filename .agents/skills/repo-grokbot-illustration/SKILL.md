# 仓库形象与 Grokbot 插画

为指定仓库设计能表达项目用途的形象，再制作可用于 Erika 的插画。以 [Grokbot Icon Studio](https://grokbot-icon-studio.serio-ai.chatgpt.site/zh-hans) 为风格参考。

## 获取参考提示词

生成插画前，默认尝试获取页面当前的参考提示词。用户明确要求跳过参考页面时，遵循用户要求。

1. 打开上面的中文页面。如果普通网页工具无法读取，使用可用的浏览器交互工具打开页面；一次网页工具失败不代表页面不可访问。
2. 选择“复制精简版提示词”或“复制完整版提示词”。等待复制成功提示，再读取浏览器剪贴板。两版提示词都是韩文。如果读取为空或仍是之前的内容，检查页面状态，重新复制并读取。
3. 根据实际获取的提示词和用户要求设计插画。页面也提供在 ChatGPT 中使用各版本的链接。

只有在浏览器不可用、页面无法打开、复制控件不可用或复制后仍无法读取等情况下，才视为获取失败。报告具体失败步骤，不要笼统地声称页面不可访问。如果用户明确要求使用原始提示词或先核对页面，获取失败后暂停依赖提示词的工作，请用户提供提示词或选择下一步。否则说明限制，使用下方已核对的特征继续。

精简版适合快速参考。完整版提供更详细的外观保留、构图、冲突处理和修改规则。提示词原本面向已有角色图的转换：已有参考图时，保留其可识别特征；从仓库创作新形象时，先设计角色，再将选定特征用于生成，不要虚构参考图。仅提炼必要规则，不将网站原文整段收录到仓库。

参考页面的关键特征是：方形画布；圆润的大脸；两只平行、纯黑、竖直的胶囊形眼睛；没有鼻子、嘴和眼部高光；淡色椭圆腮红；头部从左下探入，顺时针倾斜约 15°，左侧和下侧自然裁切，右上角留白；大块简化的头发、平涂、少量阴影和纯色深炭灰背景。完整版强调保留原角色的肤色或表面颜色、发色和轮廓，避免照搬原角色的眼睛及表情。用户的明确要求优先；按 Erika 的用途调整背景时，仍保留右上角均匀留白。

## 理解仓库

确认目标仓库。用户未另行指定时，使用当前仓库；用户指定其他仓库时，检查该仓库的可用资料。先阅读 README、项目描述和相关视觉资源，了解用途、受众、名称、现有形象与配色。区分仓库事实和设计推测。资料不足时，只询问会影响设计的关键问题。

保留用户提供的参考图、已有角色和明确要求。将项目特点转化为可见的造型、服饰或道具，避免只依赖项目名或编程语言。不要擅自改变已有品牌形象。

## 确定设计方向

用户已指定角色或明确要求直接生成时，按要求继续。方向尚不明确且选择会明显影响结果时，提出几个差异清晰的方案，说明每个方案的角色、项目关联、配色和气质。根据用户需求，用文字或概念草图呈现；用户要求视觉比较时，生成可辨认的草图。

如果用户要求先选方案，展示方案后等待选择，再生成最终插画。接受用户混合或修改方案；不要把等待选择变成所有任务的必经步骤。

## 生成插画

使用可用的图像生成工具，并遵循其图像生成或编辑流程。根据选定方向描述角色、姿态、轮廓、材质、配色和构图，生成完整插画，而不只是交付提示词。需要保持已有角色一致时，将用户提供的参考图交给图像工具。图像工具不可用时，说明限制，并提供可直接使用的提示词。

以核对过的 Grokbot 视觉特征为基础，结合选定的角色设计生成。除非用户另有要求，画面不包含文字、水印或 Banner 信息。

用于 Erika 默认 `grokbot` 模板时，主体应清晰、适合方形裁切；背景使用均匀纯色，右上角保留干净的背景区域，以便 Banner 采样和融合。用户需要透明版本时，另生成或编辑透明背景版本，保持角色设计一致。不要把有色背景文件误称为透明文件。

## 交付

展示生成结果，并说明设计与仓库的关联。用户要求将图像用于仓库时，默认保存到目标仓库的 `assets/grokbot-icon.png` 或 `assets/grokbot-icon.webp`；透明版本可保存为 `assets/erika-icon-transparent.png`。遵循用户指定的路径和格式。保存前检查目标文件是否存在；如果替换现有素材的意图不明确，先保留原文件并展示新结果。检查实际文件格式、尺寸和透明度，并说明交付路径。未写入仓库时，提供图像工具返回的结果。
